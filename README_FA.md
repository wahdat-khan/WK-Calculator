# WK Calculator — نسخه دارای عکس پس‌زمینه

ماشین‌حساب اندروید با طراحی سرمه‌ای و طلایی و عکس پس‌زمینه‌ای که کاربر فرستاده است.

## امکانات
- جمع، تفریق، ضرب و تقسیم
- فیصدی، اعشار، تغییر علامت و حذف رقم آخر
- عکس پس‌زمینه اختصاصی

## ساخت فایل APK در Android Studio
1. Android Studio را نصب و اجرا کنید.
2. فایل ZIP را استخراج کنید.
3. از Android Studio گزینه Open را بزنید و پوشه `WK_Calculator_Android` را انتخاب کنید.
4. اجازه دهید Gradle Sync تکمیل شود.
5. از منو گزینه **Build → Build Bundle(s) / APK(s) → Build APK(s)** را انتخاب کنید.
6. فایل خروجی در مسیر زیر ساخته می‌شود:
   `app/build/outputs/apk/debug/app-debug.apk`

## نصب روی موبایل
فایل `app-debug.apk` را به موبایل اندروید انتقال دهید، باز کنید و Install را بزنید. اگر لازم شد اجازه نصب از این منبع را در تنظیمات اندروید فعال کنید.

یادآوری: این ZIP سورس پروژه است و خودش فایل APK کامپایل‌شده نیست.
